# ☕ Baltazarte

Uma plataforma de e-commerce moderna e responsiva para a venda de canecas personalizadas, construída com:

- ▲ Next.js para renderização no servidor e roteamento otimizado
- ⚛️ React + TypeScript para uma interface robusta e tipada
- 🗄️ Prisma ORM para gerenciamento completo do banco de dados
- 🧩 RTK Query para consumo de API e gerenciamento de estado
- 💳 Fluxo de pagamento completo e seguro com Stripe
- 🚚 Integração com a API do Melhor Envio para cálculo de frete
- 📧 Sistema de envio de e-mails para notificações
- 🔐 Middleware de autenticação com proteção de rotas

## 🌐 Acesse a página ao vivo: [Baltazarte](https://baltazarte.vercel.app/products)

## 📦 Tech Stack

**Next.js** – Framework React para SSR, SSG e roteamento otimizado.
**React + TypeScript** – UI baseada em componentes com tipagem estática.
**Prisma** – ORM moderno para queries, migrations e gerenciamento de schema.
**RTK Query** – Ferramenta para data fetching e caching integrada ao Redux Toolkit.
**Stripe** – Processamento de pagamentos seguro e completo.
**Melhor Envio** – API para cálculo de frete em tempo real.
**Styled Components** – Estilização CSS-in-JS para componentes.
**Vercel** – Plataforma de hospedagem e deploy para aplicações web modernas.

## ✅ Features

- **Design Responsivo:** Experiência de usuário otimizada para desktops, tablets e celulares.
- **Autenticação Completa:** Sistema de login, logout e registro para usuários.
- **Níveis de Permissão:** Distinção entre usuários comuns e administradores com acesso a funcionalidades exclusivas.
- **Dashboard de Admin:** Interface para gerenciamento completo de produtos (criar, editar, deletar), categorias e pedidos.
- **Dashboard de Usuário:** Área para gerenciamento de endereços e visualização do histórico de pedidos.
- **Fluxo de Pagamento Seguro:** Integração ponta a ponta com Stripe, desde a intenção de pagamento até a confirmação via webhooks.
- **Cálculo de Frete:** Consulta em tempo real das opções de frete através da API do Melhor Envio.
- **Proteção de Rotas:** Middleware que protege rotas de admin e de usuário, garantindo que apenas usuários autenticados e autorizados tenham acesso.
- **Notificações por E-mail:** Envio de e-mails de confirmação de cadastro e respostas a mensagens de contato.
